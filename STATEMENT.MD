# Problem Statement

Managing books and members manually in a library can be time-consuming and may lead to difficulties in maintaining accurate records. It can also make it difficult to track which books are available or issued.

The proposed **Library Management System** provides a simple Java-based solution for managing books, members, and book issue/return records efficiently.

## Scope of the Project

The system focuses on basic library management operations, including:

* Adding and managing books
* Searching and viewing books
* Removing books
* Registering library members
* Viewing member information
* Issuing books to members
* Returning books
* Tracking currently issued books
* Storing library records using text files

The project is intended for basic library operations and can be enhanced with additional features in the future.

## Target Users

The primary users of the system are:

* **Librarians** – to manage books, members, and issue/return records.
* **Library Staff** – to maintain and view library information.
* **Students/Members** – indirectly benefit from faster book searching and availability checking.

## High-Level Features

### 1. Book Management

* Add new books
* View all books
* Search books by ID, title, or author
* Remove books
* Check book availability

### 2. Member Management

* Register new members
* View registered members
* Store member details

### 3. Book Issue and Return

* Issue available books
* Return issued books
* Prevent issuing an already issued book
* Track issued books and members

### 4. Data Storage

* Store book records in `books.txt`
* Store member records in `members.txt`
* Store issue records in `issue_records.txt`

## Expected Outcome

The project aims to provide a simple, organized, and reliable system for performing common library management operations while demonstrating Java programming concepts such as classes, objects, collections, file handling, validation, and modular programming.
